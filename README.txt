BENELEE CHRISTMAS CO. WEBSITE
=============================
Slogan: Bring the Magic Home.
WhatsApp: 075 073 2008

FILES
-----
index.html      Main storefront
style.css       Festive responsive design and animations
script.js       Full catalogue, filters, cart, countdown and WhatsApp automation
about.html      About page
contact.html    WhatsApp contact page
shipping.html   Delivery information
terms.html      Terms/product information
images/         Place your own/licensed product photos here

CATALOGUE
---------
The site contains the products and suggested retail prices requested across categories 1–11 plus the bundle section. Prices should be checked against supplier costs before publishing.

PHOTOS
------
The current storefront uses polished festive visual placeholders/emoji so it works immediately without third-party image licensing. Replace the product visual area with your own supplier/licensed images when you have them. Do not copy retailer photos without permission.

WHATSAPP
--------
All product WhatsApp buttons automatically create a message containing the clicked product name and price. The cart can also generate one combined order message.

DEPLOYMENT
----------
Upload the complete folder to GitHub Pages, Netlify, Vercel or another static host. No server is required for the catalogue/cart/WhatsApp flow.

LOGO
----
Replace the text logo in the header/footer with Benelee's final logo once designed.
